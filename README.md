# Psysis_8 — Библиотека Опыта (БО840)

> **Карта — не территория. Модель — не человек. Инструмент — не истина.**

## Правила работы

### 1. Вход через тег
Любая тема открывается через тег. Начинай с поиска по тегу — это даст контекст и связи.

### 2. Одна тема — один файл
Каждый узел Библиотеки — отдельный файл. Это позволяет его дополнять, не разрушая остальное.

### 3. Запись по шаблону
Любая новая запись начинается с шаблона (см. `09_TEMPLATES.md`).

### 4. Связи через теги
Связи между темами создаются через теги, а не через текст. Если тег есть — связь есть.

### 5. Приоритет реальности
Любое правило пересматривается, если реальность его опровергает.

## Теги и правила

Все теги заносятся в `08_TAGS.md`. Формат: `#префикс_название` (нижний регистр, без пробелов).

Префиксы:
- `#аксиома_` — базовые законы
- `#переменная_` — измеряемые параметры
- `#механика_` — процессы
- `#эмоция_` — эмоции
- `#ловушка_` — типовые ошибки прогноза
- `#метод_` — инструменты
- `#протокол_` — алгоритмы
- `#кейс_` — примеры
- `#детское_правило_` — источники ловушек

## Быстрый чек-лист

1. Найди тег, ближе всего к твоей теме.
2. Открой соответствующий файл.
3. Прочитай тезисы.
4. Если нужно — добавь свой кейс по шаблону.
5. Свяжи его тегами с существующими узлами.
