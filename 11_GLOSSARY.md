# Глоссарий

**Теги:** `#мета` `#глоссарий` `#термины`

---

## А

| Термин | Определение |
| :--- | :--- |
| **AG_flow** | Энергия действия. Скорость и сила, с которой система направляет внимание на задачу. Источник — влечение (L0). |
| **att/s** | Доступное внимание. Конечный когнитивный ресурс. |

---

## В

| Термин | Определение |
| :--- | :--- |
| **Вина** | Состояние при нарушении обязательства. Связана с поступком. Можно исправить (извиниться, компенсировать). |
| **Влечение** | Первичный бессознательный импульс (L0). Не имеет фиксированного объекта. Источник AG_flow. |

---

## Г

| Термин | Определение |
| :--- | :--- |
| **Граф опыта** | Структура памяти и правил. Узлы — опыты, правила, убеждения. Рёбра — связи между ними. |

---

## Д

| Термин | Определение |
| :--- | :--- |
| **D_core** | Ядро личности. Набор принципов и правил, которые человек защищает как «свои». |
| **D_soc** | Социальное ядро. Нормы и правила, взятые из группы. |
| **Дельта (ΔI)** | Разрыв между прогнозом и реальностью. Источник эмоции и сигнал для перестройки графа. |
| **Диссоциация** | Разрыв связи в графе. Может быть инструментом (осознанно) или травмой (вне воли). |

---

## К

| Термин | Определение |
| :--- | :--- |
| **К** | Коэффициент комплементарности пары. K > 1 — симбиоз, K < 1 — конфликт. |
| **Карта мира** | Модель реальности, построенная из сигналов, опыта и воображения. |

---

## Л

| Термин | Определение |
| :--- | :--- |
| **Ловушка** | Ошибка прогноза, ведущая в тупик. Неправильные данные, интерпретация или вывод. |

---

## М

| Термин | Определение |
| :--- | :--- |
| **Мудрость** | Интегральный показатель связности графа. Чем больше связей между узлами, тем выше устойчивость системы. |

---

## Н

| Термин | Определение |
| :--- | :--- |
| **Наказание** | Социально санкционированное действие. Подтверждает нарушение, уравновешивает вину, очищает нарушителя. |
| **Норма** | Конвенция, признанная группой. Не абсолютна — пересматривается под давлением реальности. |

---

## П

| Термин | Определение |
| :--- | :--- |
| **П0** | Базовая граница. «Твоя свобода заканчивается там, где начинается свобода другого». Право на «нет» без разрушения связи. |
| **P_heat** | Внутренний перегрев / шум. Накопленная энергия без выхода. Блокирует мышление при P_heat > 8. |
| **Привязанность** | Устойчивая связь (L4). Выходит за рамки импульса. «Я выбираю его / её каждый день». |

---

## С

| Термин | Определение |
| :--- | :--- |
| **S** | Соматический дискомфорт. Тело как носитель сигнала. Усиливает катастрофизацию при S > 7. |
| **Симпатия** | Осознанная оценка влечения к конкретному объекту (L2). «Мне нравится». |
| **Совесть** | Внутренний счётчик связности графа. Сигнал: вина, когда связность падает; удовлетворение — когда растёт. |
| **Спонтанность** | Быстрое действие после завершённой фоновой обработки (низкий P_heat, высокий AG_flow). |
| **Стыд** | Страх несоответствия образу себя в глазах других. Связан с D_soc. «Я плохой». |

---

## Т

| Термин | Определение |
| :--- | :--- |
| **T** | Тревожность. Направляет достраивание карты мира: низкая T → недооценка рисков, высокая T → переоценка. |
| **Торг** | Поиск обходного пути, когда прямой путь заблокирован совестью. |
| **Травма** | Замороженная дельта подкрепленная эмоциями и соматикой, которая стала супер-правилом. |

---

## Х

| Термин | Определение |
| :--- | :--- |
| **H_self** | Честь / самоценность. Устойчивость к стыду и ложной вине. |

---

## Ш

| Термин | Определение |
| :--- | :--- |
| **Шум (рабочий)** | Конфликт узлов, ведущий к интеграции. P_heat ↑, затем ↓. Граф обновляется. |
| **Шум (хронический)** | Конфликт без выхода. P_heat постоянно высок. Граф не обновляется. |

---

## Э

| Термин | Определение |
| :--- | :--- |
| **Эмоция** | Сигнал рассогласования (ΔI). Две роли: сигнал (L2) и заряд (L0). |
| **Импульсивность** | Прорыв без обработки (высокий P_heat). Быстрое действие из-за перегрузки. |
* * *

## Е

| Термин| Определение|
| ---| ---|
| **Exp**| Опыт, который система интегрирует в граф. Отличается от события: событие случилось, Exp — это запись, которая изменила связи между узлами. |

* * *

## З

| Термин| Определение|
| ---| ---|
| **Заморозка**| Состояние, когда узел графа перестаёт обновляться. Правило остаётся прежним, хотя контекст изменился. Противоположность — интеграция. |

* * *

## И

| Термин| Определение|
| ---| ---|
| **Игра**| Добровольное изменение правил ради снижения `P_heat`, повышения `AG_flow` и получения нового `Exp` в безопасном контейнере. Признаки: правила, роли, цель, предсказуемый исход, контекст, эмоциональный заряд. В чистой игре — добровольность. При разрушенном контейнере (война, садизм) добровольность иллюзорна. |
| **Импульсивность**| Прорыв без обработки (высокий `P_heat`). Быстрое действие из-за перегрузки. |
| **Интеграция**| Процесс, при котором новый опыт встраивается в граф, меняя связи и правила. Противоположность заморозке. |

* * *

## К

| Термин| Определение|
| ---| ---|
| **K**| Коэффициент комплементарности пары. `K > 1` — симбиоз (`AG_flow` складывается), `K < 1` — конфликт (`AG_flow` тратится на трение). |
| **Калибровка**| Процесс сверки карты мира с реальностью. Сознательная проверка прогноза. |
| **Карта мира**| Модель реальности, построенная из сигналов, опыта и воображения. |
| **Контейнер (магический круг)**| Изолированное пространство, где действуют особые правила игры. Безопасен, пока границы не разрушены. |

* * *

## Л

| Термин| Определение|
| ---| ---|
| **Ловушка**| Ошибка прогноза, ведущая в тупик. Неправильные данные, интерпретация или вывод. Ловушка — это `ΔI`, обработанный через искажённый узел графа: система ожидала один прогноз, но эмоциональный шум (`P_heat`) изменил вес связей, и вывод оказался инвертирован. |
| **Любовь (условная)**| Игра, где `H_self` зависит от внешней оценки (`H_ext`). «Люблю, только если…» — правило с результатом. |

* * *

## М

| Термин| Определение|
| ---| ---|
| **Маска**| Временный узел `D_soc`, наложенный на `D_core` для конкретной социальной игры. Потребляет `att/s` на поддержание. |
| **Мудрость**| Интегральный показатель связности графа. Чем больше связей между узлами, тем выше устойчивость системы. Мудрость — это способность пересматривать правила, не теряя себя. Не сумма знаний, а связность всего графа, включая `D_core` и `D_soc`. |

* * *

## Р

| Термин| Определение|
| ---| ---|
| **Ригидность**| Неспособность пересмотреть правило даже при появлении новых данных. Блокирует обновление `D_core`. |

* * *

## С

| Термин| Определение|
| ---| ---|
| **S**| Соматический дискомфорт. Тело как носитель сигнала. Усиливает катастрофизацию при `S > 7`. |
| **Садизм**| Игра контроля с фатальными ставками. `AG_flow` садиста подпитывается `P_heat` жертвы. `П0` жертвы нарушен. `#ловушка_игра_фатальная` |
| **Симпатия**| Осознанная оценка влечения к конкретному объекту (L2). «Мне нравится». |
| **Совесть**| Внутренний счётчик связности графа. Считает цену перестройки графа под текущий контекст. Сигнал: вина, когда связность падает; удовлетворение — когда растёт. |
| **Состояние**| Режим без роли, правил и счёта. Полюс спектра «игра — состояние». Пример: присутствие, боль, творчество без цели. |
| **Социальные игры**| Повторяющиеся последовательности действий с ролями, правилами и предсказуемым исходом. Ссоры, флирт, корпоративные войны, сплетни, молчаливая обида. Отличаются от состояния. Полное определение → `15_SOCIAL_GAMES.md` |
| **Спонтанность**| Быстрое действие после завершённой фоновой обработки (низкий `P_heat`, высокий `AG_flow`). |
| **Стыд**| Страх несоответствия образу себя в глазах других. Связан с `D_soc`. «Я плохой». |
| **Супер-правило**| Правило, которое стало абсолютным и не пересматривается. Часто — результат травмы. Пример: «Я не имею права ошибаться». |

| **Уровни (L0–L5)**| Уровни системы: L0 — тело/влечение, L1 — безопасность, L2 — статус/внимание, L3 — авторство, L4 — смыслы/привязанность, L5 — трансцендентное. Каждая переменная и ловушка привязаны к уровню. |

## Х

| **H_self**| Честь / самоценность. Устойчивость к стыду и ложной вине. |
